## Описание

ValutaTrade Hub — консольное приложение на Python для управления виртуальным валютным портфелем и отслеживания валютных курсов.

Программа позволяет регистрировать пользователей, покупать и продавать виртуальные валюты, просматривать портфель, рассчитывать его стоимость и получать актуальные котировки из внешних API.

Дополнительно реализованы:

- безопасное хранение паролей с солью и хешированием;
- валидация данных и обработка ошибок;
- загрузка курсов из CoinGecko и ExchangeRate API;
- кеширование котировок с TTL и автоматическим обновлением;
- сохранение истории валютных курсов;
- логирование операций и ошибок;
- автоматические тесты.

Приложение моделирует торговые операции и не работает с реальными денежными средствами.

## Требования

- Python 3.12 или новее;
- менеджер зависимостей `uv`;
- интернет-соединение для обновления курсов;
- API-ключ ExchangeRate API для получения фиатных котировок.

Основные зависимости: `requests`, `prettytable`. Для проверки качества кода используется `ruff`.

## Доступные команды

| Команда | Назначение |
|---|---|
| `register --username NAME --password PASSWORD` | Регистрация |
| `login --username NAME --password PASSWORD` | Авторизация |
| `logout` | Выход из учётной записи |
| `whoami` | Информация о текущем пользователе |
| `show-portfolio [--base CODE]` | Просмотр портфеля |
| `buy --currency CODE --amount NUMBER` | Покупка валюты |
| `sell --currency CODE --amount NUMBER` | Продажа валюты |
| `get-rate --from CODE --to CODE` | Получение прямого и обратного курсов |
| `update-rates [--source coingecko\|exchangerate]` | Обновление котировок |
| `show-rates [--currency CODE] [--top N] [--base CODE]` | Просмотр сохранённых курсов |
| `help [команда]` | Справка |
| `exit` | Завершение работы |

Если обязательные аргументы не переданы, программа запрашивает их интерактивно. Команды управления портфелем требуют авторизации.

## Пример использования

Ниже приведён полный сценарий работы с виртуальным портфелем.

### 1. Регистрация и авторизация

    register --username trader --password StrongPass123
    login --username trader --password StrongPass123
    whoami

После регистрации создаются пользователь и пустой портфель. Повторная регистрация с тем же именем запрещена без учёта регистра.

### 2. Обновление валютных курсов

    update-rates --source coingecko

Программа загружает котировки BTC, ETH и SOL и сообщает количество полученных и сохранённых курсов.

Для обновления всех источников:

    update-rates

Для фиатных валют:

    update-rates --source exchangerate

### 3. Просмотр котировок

    show-rates
    show-rates --currency BTC
    show-rates --top 3
    show-rates --base EUR

Параметр `--top` выводит N наиболее дорогих криптовалют по стоимости в USD. Команда читает локальный кеш без обращения к API.

### 4. Покупка валюты

    buy --currency BTC --amount 0.01

Баланс BTC увеличивается на 0.01. Если кошелёк отсутствует, он создаётся автоматически.

### 5. Просмотр портфеля

    show-portfolio
    show-portfolio --base EUR

Результат отображается с помощью PrettyTable: валюта, баланс, стоимость в выбранной валюте и итоговая стоимость портфеля.

### 6. Получение курса

    get-rate --from BTC --to USD
    get-rate --from BTC --to EUR

Программа показывает прямой и обратный курсы, а также время обновления использованных котировок. При необходимости устаревшие котировки обновляются автоматически.

### 7. Продажа валюты

    sell --currency BTC --amount 0.005

Баланс BTC уменьшается на 0.005.

### 8. Обработка ошибки

    sell --currency BTC --amount 10

При недостаточном балансе программа выводит сообщение об ошибке. Средства не списываются, работа приложения продолжается.

### 9. Завершение работы

    logout
    exit

## Модель торговли

Используется упрощённая модель виртуальной торговли:

- `buy` увеличивает баланс выбранной валюты;
- `sell` уменьшает баланс;
- USD при покупке не списываются и при продаже не начисляются;
- стоимость активов рассчитывается отдельно по валютным курсам.

Поддерживаются фиатные валюты **USD, EUR, GBP, RUB** и криптовалюты **BTC, ETH, SOL**.

Для расчёта кросс-курсов используется USD. Например:

    BTC/EUR = (BTC/USD) / (EUR/USD)

Обратный курс вычисляется как `1 / курс`. Промежуточные вычисления выполняются без округления, округляется только отображаемый результат.

## Модели и бизнес-логика

**User** — пользователь с уникальным ID, именем, хешем пароля, солью и датой регистрации. Реализованы создание, проверка и изменение пароля.

**Wallet** — валютный кошелёк с неотрицательным балансом. Методы `deposit` и `withdraw` проверяют корректность суммы и достаточность средств.

**Portfolio** — портфель пользователя, содержащий валютные кошельки. Метод `get_total_value` рассчитывает стоимость активов в выбранной валюте по переданным курсам.

Бизнес-операции регистрации, авторизации, покупки, продажи и получения курсов вынесены в `core/usecases.py`.

## Parser Service и кеширование

Для загрузки котировок используются:

- **CoinGecko** — курсы BTC, ETH и SOL к USD;
- **ExchangeRate API** — курсы EUR, GBP и RUB к USD.

HTTP-запросы выполняются через `requests` с тайм-аутом 10 секунд.

Обрабатываются сетевые ошибки, некорректные ответы, HTTP 401 и 429. При частичном сбое успешно полученные курсы сохраняются. При полном отказе источников существующий кеш не удаляется.

Текущие котировки сохраняются в `data/rates.json`, история — в `data/exchange_rates.json`.

**TTL составляет 300 секунд.** Команда `get-rate` проверяет актуальность необходимых валютных пар и при необходимости запускает обновление. Если получить свежий курс не удалось, программа сообщает об ошибке.

Актуальность проверяется отдельно для каждой пары. Старые котировки не заменяют более новые.

Запись JSON выполняется через временный файл с последующей атомарной заменой.

## Хранение данных

Приложение использует четыре JSON-файла:

| Файл | Назначение |
|---|---|
| `data/users.json` | Пользователи, хеши паролей и соли |
| `data/portfolios.json` | Портфели и балансы |
| `data/rates.json` | Текущие котировки |
| `data/exchange_rates.json` | История курсов |

Пользовательские данные исключены из Git. Начальные файлы курсов включены в репозиторий.

Пароли хешируются алгоритмом PBKDF2-HMAC-SHA256 с индивидуальной случайной солью и 200 000 итераций. Для проверки используется `hmac.compare_digest`.

## Логирование и обработка ошибок

Логи записываются в:

- `logs/valutatrade.log` — действия пользователей и ошибки приложения;
- `logs/parser.log` — работа Parser Service.

Используются декораторы `log_action` и `log_errors`. Настройки приложения централизованы в `SettingsLoader`, реализующем Singleton.

API-ключ не выводится в сообщения логирования. Каталог `logs/` исключён из Git.

Приложение обрабатывает ошибки авторизации, неизвестные валюты, некорректные суммы, недостаток средств, ошибки аргументов и недоступность внешних API.

## Проверка качества кода

Запустить тесты:

    uv run python -m unittest discover -s tests -v

39 автоматических тестов проверяют модели User, Wallet и Portfolio, бизнес-операции, CLI, Parser Service, обработку ошибок API, кеширование, TTL и безопасность логирования.

Проверить Ruff:

    uv run ruff check .

Проверить форматирование:

    uv run ruff format --check .

Выполнить обе проверки:

    make lint

Используются правила E, F, I, Python 3.12 и максимальная длина строки 88 символов.
